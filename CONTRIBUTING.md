# Правила участия

Спасибо за интерес к проекту! Вот как вы можете помочь.

## Сообщение об ошибках

Перед созданием issue убедитесь, что аналогичная проблема ещё не зарегистрирована. При создании issue укажите:

- Чёткое описание проблемы
- Шаги для воспроизведения
- Ожидаемое и фактическое поведение
- Версию ОС и браузера

## Предложение улучшений

Создайте issue с тегом `enhancement` и опишите:

- Что именно вы хотите улучшить и почему
- Как это поможет другим пользователям

## Отправка изменений

1. Сделайте форк репозитория
2. Создайте ветку для вашей задачи:
   ```bash
   git checkout -b feature/название-функции
   ```
3. Внесите изменения и закоммитьте:
   ```bash
   git commit -m "Краткое описание изменения"
   ```
4. Запушьте ветку:
   ```bash
   git push origin feature/название-функции
   ```
5. Откройте Pull Request с описанием изменений

## Стиль кода

- Python: следуйте PEP 8
- HTML/CSS: отступы — 4 пробела
- JavaScript: стандарт ES6+
- Комментарии — на русском или английском языке
